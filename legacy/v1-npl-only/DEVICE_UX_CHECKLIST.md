# 24K 真机 UX 检查清单

## C 端四页

- 底部依次点击 `秒杀大厅 / 常规商城 / 线下门店 / 我的资产`，确认安全区不遮挡。
- 秒杀大厅：倒计时、接力 +30s、奖池、规则、战报、加入终核清单均有反馈。
- 常规商城：搜索、分类、现货筛选、商品详情、SKU、数量、快递/自提、库存复核、5 要素终核可用。
- 线下门店：地区筛选、距离、拨号、导航、自提行政区编码展示可用。
- 我的资产：地址仓、BNM 池、节点/直推/区域/运维收益、Claim paused 状态可用。

## 钱包与支付

- 未连接钱包点击 Claim 或终核结算会打开 Reown Connect。
- 非 BSC 时会请求切换到 BSC 56。
- 首次支付只检查 NPL allowance，不足时发送一笔无限授权，充足时跳过。
- 拒签 approve / 拒签 fund 都显示未付款提示。
- approve 成功但 fund 拒签不能标记已支付。
- pending 订单重开 App 后能恢复刷新。
- 微额主网测试只用极小金额，禁止打印私钥。

## 后台预览

- `/merchant` 能看到 SIWE、单品提报、上架死锁、发货、核销、云打印、商家 Claim。
- `/admin` 能看到审核、排期、比例、奖池、强制退款、风控、CMS、通知、审计日志。
